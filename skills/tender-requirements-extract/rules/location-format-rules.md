# Source locations

A useful locator lets another person find the observed content. Identify the file and page, section, table row or image region as appropriate. Distinguish physical PDF pages from printed numbering. For DOCX, preserve actual logical extraction locations rather than inventing Word pages. Repeated headings need enough context to disambiguate.

Cite both requirement and response sources. Actually view images before citing visible features; text extraction alone does not establish them. If a location or quote is unavailable, explain the evidence gap and seek readable material; do not fabricate a locator or discard the unresolved issue. Choose consistent notation for this project; no prescribed machine format is required.
